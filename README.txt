نظام إدارة أولاد صقر — نسخة Streamlit مستقلة

الملفات:
- app.py: البرنامج المقيد على الإدارة الصحية بأولاد صقر.
- endemic_labs_exam_v1_0.db: قاعدة البيانات المخصصة لهذه النسخة.
- requirements.txt: المكتبات المطلوبة.

التشغيل محلياً:
1) ضع الملفات الثلاثة في مجلد واحد.
2) نفّذ: pip install -r requirements.txt
3) ثم: streamlit run app.py

النشر على Streamlit Community Cloud:
1) ارفع الملفات الثلاثة إلى مستودع GitHub جديد أو مجلد مستقل.
2) اختر app.py كنقطة تشغيل في Streamlit Community Cloud.
3) استخدم قاعدة البيانات المرفقة مع هذه النسخة فقط.

مهم: هذه نسخة منفصلة؛ قاعدة البيانات الأصلية لم يتم تعديلها. احتفظ بنسخة احتياطية قبل إجراء أي تعديلات يدوية.
